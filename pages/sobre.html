Uma ferramenta para cuidar do que importa.

A FloriApp é uma aplicação informática pensada para apoiar o trabalho diário dos educadores de infância.

01 · Introdução

Organizar para acompanhar melhor

O projeto FloriApp consiste no desenvolvimento de uma aplicação informática para educadores de infância, com o objetivo de facilitar a organização de tarefas e o planeamento de atividades educativas. A aplicação pretende tornar o trabalho dos educadores mais simples e organizado, aplicando conhecimentos de programação e desenvolvimento web adquiridos ao longo do Curso Profissional de Informática.

Através de uma interface simples, a FloriApp reúne o planeamento pedagógico, tarefas do quotidiano e informação de apoio ao acompanhamento das crianças.

02 · Enquadramento teórico

Tecnologia ao serviço da educação

A informática tem um papel importante na educação, permitindo organizar informações, planear atividades e simplificar tarefas. Os educadores de infância podem beneficiar da utilização de aplicações digitais para gerir melhor o seu trabalho diário.

A FloriApp pretende apoiar estes profissionais através de funcionalidades simples e práticas. Para o seu desenvolvimento são utilizadas tecnologias web como HTML, CSS e JavaScript. A aplicação deve ser fácil de utilizar, acessível e segura, respeitando a proteção dos dados pessoais, especialmente os das crianças.

Privacidade desde o início.

Esta versão é um protótipo local para demonstração. Os dados ficam neste dispositivo; não introduzas nomes, fotografias ou informação sensível de crianças.
