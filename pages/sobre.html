Projeto de desenvolvimento web · Floricultura e jardinagem

Uma ferramenta para cuidar do que cresce.

A FloriApp é uma aplicação pensada para apoiar a gestão diária de regas, fertilização e manutenção de plantas e flores.

01 · Introdução

Organizar para cuidar melhor

O projeto FloriApp consiste no desenvolvimento de uma aplicação web para gestão de floricultura, com o objetivo de facilitar a organização de tarefas, registos de cuidados e planeamento semanal do jardim. A aplicação pretende tornar o trabalho de manutenção mais simples, claro e eficiente, aplicando conhecimentos de programação e desenvolvimento web.

Através de uma interface simples, a FloriApp reúne a agenda de atividades, as tarefas de manutenção e a observação do estado das plantas para apoiar a saúde geral do jardim.

02 · Enquadramento teórico

Tecnologia ao serviço da jardinagem

A informática tem um papel importante na gestão de espaços verdes, permitindo organizar informações, planear cuidados e simplificar tarefas do dia a dia. Floricultores, jardineiros e pequenos negócios de horticultura podem beneficiar da utilização de aplicações digitais para gerir melhor as suas operações.

A FloriApp pretende apoiar estes profissionais através de funcionalidades simples e práticas. Para o seu desenvolvimento são utilizadas tecnologias web como HTML, CSS e JavaScript. A aplicação deve ser fácil de utilizar, acessível e segura, respeitando a proteção dos dados do negócio e dos clientes.

Privacidade desde o início.

Esta versão é um protótipo local para demonstração. Os dados ficam neste dispositivo; evita introduzir informação sensível de clientes, fornecedores ou plantas com dados privados.
